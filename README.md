# BMZ Artesiano — Limpeza de Poço Artesiano e Conserto de Bombas

Landing page moderna e responsiva para a **BMZ Artesiano**, especializada em limpeza e desinfecção de poços artesianos, manutenção preventiva e conserto/saque de bombas submersas.

## 🚀 Tecnologias

- **React 19**
- **TypeScript**
- **Vite**
- **Tailwind CSS v4**
- **Lucide Icons**
- **Framer Motion**

## 📦 Como Rodar Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/tiagomv/bmz-artesiano.git
   cd bmz-artesiano
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

4. Para gerar a build de produção:
   ```bash
   npm run build
   ```
